# وب‌سایت جمیله زاهدیان

هوم‌پیج فارسی و واکنش‌گرا برای مرکز تخصصی رنگ، لایت، کراتین، احیای مو و آموزش جمیله زاهدیان. طراحی بر اساس هویت کرم، طلایی و مشکی لوگوی اصلی انجام شده و از تصاویر واقعی ارسالی استفاده می‌کند.

## اجرا

```bash
npm install
npm run dev
```

بیلد تولیدی:

```bash
npm run build
```

## دارایی‌های تصویری

- تصاویر باکیفیت تحویلی: `public/assets/portfolio/edited`
- نسخه‌های بهینه وب: `public/assets/portfolio/web`
- لوگوی اصلی: `public/assets/brand`
- گزارش انتخاب و کنترل کیفیت: `docs/asset-selection.md`

هیچ‌یک از تصاویر و لوگو بازسازی یا بازطراحی نشده‌اند. ویرایش‌ها محدود به اصلاح غیرمولد نور، رنگ، کنتراست، کراپ و بهینه‌سازی وب هستند.
