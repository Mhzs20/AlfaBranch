# Kazhe Beauty — Amadeh

صفحه اصلی کاژه بیوتی بر اساس طرح نهایی گفتگو، با دیزاین RTL، گلس‌مورفیسم لوکس و استفاده از تصاویر واقعی ارائه‌شده برای پروژه.

## اجرا روی لوکال

```bash
npm install
npm run dev
```

سپس آدرس نمایش داده‌شده توسط Vite را در مرورگر باز کنید.

## بیلد پروداکشن

```bash
npm run build
npm run preview
```

## ساختار محتوا

- Hero + برند کاژه
- خدمات: ناخن، میکاپ، شینیون، خدمات مو
- گالری کامل نمونه‌کار ناخن
- میکاپ و زیبایی عروس
- شینیون و استایل عروس
- خدمات مو با تصاویر واقعی نمونه‌کار و استایل
- درباره کاژه و CTA رزرو

> لینک‌های اینستاگرام، واتساپ و شماره تماس فعلاً placeholder هستند و بعد از دریافت اطلاعات قطعی سالن باید جایگزین شوند.
